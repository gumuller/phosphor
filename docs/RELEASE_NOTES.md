Phosphor's first Linux preview: a local-first notebook with formatted editing, raw Markdown, green CRT bloom, notebooks, tags, favorites, search and recoverable trash.

**Download `Phosphor-__VERSION__-linux-x86_64.AppImage` for the simplest portable option.** Make it executable in your file manager's Properties dialog, then double-click it. `INSTALL.txt` includes terminal commands and a FUSE-free launch option.

The optional `.deb` installs a menu launcher on Debian/Ubuntu. `SHA256SUMS` verifies the downloaded files. Node.js, Rust and a development server are not required to run the app.

Built on Ubuntu 22.04 for Linux x86_64 (glibc 2.35+). Packaged startup is checked under Xvfb with disposable note data. Full interactive desktop testing and other Linux distributions remain to be validated. Windows, macOS and ARM packages are not part of this release.

Notes stay in the user's application-data directory and are not included in the download. Updates are manual; automatic backups and cloud sync are not included in this preview.
